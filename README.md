# 2d-basal-melt-ice-shelves

# Code

The Idealised.ipynb code is for the idealised cases. Real_shelves.ipynb code is for modelling the shape and thermodynamic properties of some Antarctic ice shelves, before calculating their melt rates.

# Required datasets

The following datasets are required for the code.

*World Ocean Atlas 2023*

woa23_decav81B0_t00_04.nc is from NOAA's World Ocean Atlas 2023 (https://www.ncei.noaa.gov/access/world-ocean-atlas-2023/).

*BEDMAP*

bm3_bed.tif 
bm3_surface.tif 
bm3_thickness.tif 
bm3_masks.tif

are from the British Antarctic Survey's BEDMAP2 dataset (https://www.bas.ac.uk/project/bedmap-2/).
